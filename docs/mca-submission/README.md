## ⚠ Academic integrity — read before submitting

1. **Rewrite in your own words.** These are factual scaffolds of *your* project. The rubric
   requires original work and a **similarity index under 20%**. Do not paste verbatim.
2. **Verify every citation.** The reference list in file 04 lists *real, representative*
   works but you must confirm each full APA entry (author, year, title, DOI) before using it —
   do not cite anything you have not opened.
3. **Run the plagiarism check** and attach the summary at the end of the report.
4. **The declaration is true** — this is your codebase. Keep it true by writing the prose yourself.

## Formatting checklist (mechanical, but graded)

- [ ] Times New Roman — 14pt bold headings, 12pt body
- [ ] 1.5 line spacing, justified body, centred headings
- [ ] Margins 1″ (25mm) all sides
- [ ] Page numbers bottom-centre, starting from the main section
- [ ] Tables/figures numbered sequentially with captions (table above, graph below)
- [ ] 45–65 pages total
- [ ] Title page, Declaration, Certificate (faculty-signed), Acknowledgement, Executive Summary, ToC, List of Tables, List of Graphs
- [ ] APA references + plagiarism report attached
